# BERETS Plot

Локальная программа для рисования и письма на Bambu Lab с установленным держателем ручки, маркера или карандаша. Работает в браузере на **Ubuntu и Windows**; сервер запускается на твоём компьютере.

## Запуск

Установи [Node.js 22 LTS](https://nodejs.org/) версии 22.12 или новее.

- **Windows:** распакуй проект и открой `START-WINDOWS.cmd`.
- **Ubuntu:** распакуй проект и выполни `bash START-LINUX.sh`.

Первый запуск установит зависимости и при необходимости соберёт интерфейс. Дождись запуска сервера. Приложение откроется в браузере: **http://127.0.0.1:5426**. Интернет нужен для первоначальной установки зависимостей; для рисования нужна локальная сеть с принтером.

Из исходников можно запускать вручную:

```sh
npm ci
npm run build
npm start
```

Терминал сервера должен оставаться открытым. Для завершения нажми `Ctrl+C`. Программа не добавляет себя в автозапуск.

## Возможности

- Текст, размер шрифта, межстрочный интервал, выравнивание и списки.
- Штриховые шрифты, контурные шрифты Liberation и рукописный Caveat с кириллицей.
- Импорт TXT, DOCX, SVG, PNG и JPG; простые смайлики.
- Предпросмотр стола и листа A4, перемещение и изменение размеров объектов мышью.
- Просмотр траектории, экспорт SVG и G-code, сохранение проектов `.berets.json`.
- Отдельные профили ручки, маркера и карандаша с сохранением высоты переездов.
- Русский и английский интерфейс, светлая и тёмная темы.

Форматирование применяется ко всему текстовому объекту. Импорт DOCX не сохраняет все возможности Word. Растровые изображения переводятся в линии; поддерживается ограниченный набор смайликов.

## Подключение и рисование

Подключи компьютер и принтер к одной локальной сети. Введи IP, серийный номер и LAN-код принтера. Для стороннего управления может понадобиться LAN/Developer Mode — это зависит от прошивки.

Поставь рисунок в доступную область, выбери инструмент и высоту переезда, проверь траекторию. Кнопка «Домой и рисовать» отправляет подготовленный файл на SD-карту по FTPS и запрашивает запуск у принтера. SD-карта должна быть установлена и доступна для записи. Также можно экспортировать G-code и самостоятельно записать его на карту.

Сопло при рисовании располагается на Z=1 мм. Значение переезда в профиле задаёт зазор кончика над бумагой с учётом принятого выступа инструмента. Реальный выступ и смещение держателя должны соответствовать настройкам. Скорость рисования и переездов задаётся отдельно внутри генератора; оценка времени приблизительная.

Программа ориентирована на A1. Наличие других профилей не означает, что они проверены на каждом принтере. После изменения крепления сначала проверь небольшой рисунок. Успешный ответ прошивки означает принятие команды, а не подтверждение физического результата.

## Данные

IP и LAN-код сохраняются локально в браузере и не включаются в экспорт проекта. Сервер слушает только localhost. Файлы проекта переносимы между Ubuntu и Windows; подключения к принтеру настраиваются отдельно на каждом компьютере.

## Разработка

```sh
npm test
npm run build
```

Для разработки интерфейса запусти `npm run dev` и `npm run server` в отдельных терминалах. Проверки GitHub Actions выполняются на Ubuntu и Windows.
